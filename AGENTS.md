# User's first-priority website image rule

## Highest-priority image rule

- Never use AI-generated photos or synthetic player imagery on any website the user owns.
- Use real, verifiable WNBA, team, player, or editorial photography. Prefer official WNBA or team media and include the available source credit.
- Do not use generative fill, generated athlete portraits, or edits that change a player's face, uniform, or on-court appearance.
- If a suitable real image cannot be verified, use the supplied real image, a real headshot, or a text-based treatment. Do not generate a replacement.

This is a standing user requirement for every website and every site page or asset. It takes priority over image-generation defaults in all projects.
